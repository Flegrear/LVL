# LVL

LVL is a **local-first video player and media Library** for series, anime, comics, and movies.

## Getting started

Download **LVL-Setup.exe** from [here](https://github.com/Flegrear/LVL/releases/download/v0.2.0/LVL-Setup.exe). It installs the newest version, and LVL updates itself from then on. The installed app uses **127.0.0.1:4273** for its desktop window and browser tabs, sharing one Library.

LVL stores application data locally; catalog, subtitle, and torrent services may be contacted when used.
